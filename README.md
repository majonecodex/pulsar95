# Pulsar95 ✦

> Cosmic chat for the retro web.

A Windows 95-styled chat app built with vanilla JavaScript, powered by Supabase.

**🔗 Live:** https://pulsar95.vercel.app

## Features

- 🖥️ **Full Win95 desktop** — boot sequence, taskbar, Start menu
- 🎨 **9 color themes** — including Hot Dog Stand 🔥
- 🖱️ **Draggable windows** with position memory
- 🔊 **Synthesized sounds** — no external audio files
- 💬 **Realtime chat** — WebSocket via Supabase
- 🖼️ **Image uploads** — Supabase Storage
- 🎫 **Invite codes** — share any room via 6-char link
- ⌨️ **Typing indicators** — powered by Supabase Presence
- 🔒 **Row Level Security** — owner/author-only delete

## Tech Stack

| Layer | Tech |
|---|---|
| Frontend | Vanilla JS (ES modules), HTML, CSS |
| Styling | 98.css + custom CSS variables |
| Backend | Supabase (Postgres + Auth + Storage + Realtime) |
| Hosting | Vercel |
