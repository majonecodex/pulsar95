
**Powered by Groq (Llama 3.3 70B)** — one of the fastest LLMs available.

The bot:
- Keeps context of the last ~10 messages
- Replies in 1–3 sentences (short, punchy)
- Matches your language — English or Bahasa Malaysia
- Has a retro 90s tech personality
- Occasionally drops Windows 95 nostalgia references

### 🔊 Sounds & Feedback

8 synthesized retro sounds (no external files):
- 🔔 Boot chime
- 📤 Message send whoosh
- 📥 New message beep
- 🖱️ UI click
- ❓ Error ding
- ✅ Success chime
- 🔔 Login notify
- 🔌 Shutdown tone

Toggle mute by clicking the 🔊 in the system tray.

### 🖱️ Context Menus Everywhere

Right-click on:
- **Rooms** → Open, Invite, Rename, Delete, Properties
- **Channels** → Open, Rename, Delete, Copy Name, Properties
- **Messages** → Copy Text, Copy Author, Delete, Properties
- **Desktop** → Refresh, Arrange Icons, New Room, New Channel, Properties
- **Taskbar** → Cascade, Tile, Minimize All

### 📱 Mobile-Ready

- Full mobile UI with **slide-in drawers**
- Safe-area aware for notched phones (iPhone, etc.)
- **No iOS zoom** on inputs (16px minimum)
- 44px minimum tap targets everywhere
- Fixed composer at bottom, keyboard-aware
- Taskbar hidden on mobile for more screen space

## 🏆 What Makes Pulsar95 Different

**It's not a chat app with a Win95 skin.** It's a Win95 desktop that happens to have a chat app inside it.

- **Zero dependencies** — no npm packages, no build step, no framework
- **Everything synthesized** — sounds generated via Web Audio API
- **Themes via CSS variables** — switch without reloading
- **$0/month infrastructure** — free tiers cover real usage
- **~5,000 lines** of vanilla JavaScript across 7 files

| Layer | Tech |
